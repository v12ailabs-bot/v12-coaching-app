# V12 Coach Playbook (read-aloud handoff)

This folder teaches the coach how to run the whole V12 app like a high-performing coach.
It is separate from `HANDOFF.md` (which is the engineering handoff). Nothing here changes the app.

Written from the code as of 2026-10-12. Where something is not finished, not tested in a browser,
or needs a decision, it says so in plain words (see `05_KNOWN_GAPS_AND_TODOS.md`).

## Files, in the order to read them
| # | File | What it is | Read-aloud time |
|---|------|------------|-----------------|
| 0 | `ASSISTANT_PROMPT.md` | The flow prompt: how the assistant should teach and read this back | 2 min |
| 1 | `01_READ_ALOUD_SCRIPT.md` | The whole app as one spoken walkthrough: a coach's day, week, month | 35 min |
| 2 | `02_SCREEN_BY_SCREEN.md` | Every screen: where it is, what it shows, what to click | reference |
| 3 | `03_CHECKLISTS.md` | Daily / weekly / monthly / new-client / phase / taper checklists | 10 min |
| 4 | `04_ADVISORY_VS_AUTOMATIC.md` | What the app does by itself vs. what only YOU can decide | 5 min |
| 5 | `05_KNOWN_GAPS_AND_TODOS.md` | Honest list of unfinished things and your to-dos | 5 min |
| 6 | `06_OBSOLETE_AND_OVERLAP_REPORT.md` | Features that overlap or are leftovers (scan result) | 5 min |

## The one-sentence version
V12 is a coaching cockpit: clients log, the app measures and flags, the AI only *suggests*, and you
*decide*. Your job each day is to read the flags, make a few decisions, and send a few messages.
