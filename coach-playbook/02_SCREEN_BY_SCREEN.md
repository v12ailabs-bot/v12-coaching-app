# Screen by screen (coach side first, then what the client sees)

Left menu for the coach (top to bottom): **Overview, Clients, Leads / CRM, Business + Content, Assessments, Progression, Library.**

## COACH

### Overview (Coach Dashboard)
Where you start. Number cards, **Client Overview** table (click a client to open them), **Alerts & At-Risk Clients** (click a row → Intervention window), Onboarding alerts, Milestone alerts, **Phase Check-ins Due**, **Plan Checkpoints Due**, client messages, check-in overview, quick analytics, recent activity, recent notes, program subscribers, **Upgrade Requests**.
- Intervention window tabs: **Overview** (primary issue, evidence, recommended intervention with Approve / Edit / Dismiss or *Run quick review*, key numbers as of yesterday), **Strength**, **Body**, **Data**, **History**. *Open Client →* at the bottom.

### Clients
Pick a client from the list. Tabs: **Overview, Goals** (not for program-only), **Nutrition, Program Phase, Head Coach** (not for program-only).
- **Overview tab:** header with last check-in; **Attention Needed**, **Key Insights**, **Check-In Values**, **Nutrition Adherence**, **Today's Targets**, **Daily Habits**, **Coach Actions**; **Quick Actions** box (Add Note, Send Message, Schedule Call, Adjust Program → opens Program Phase, More Actions → Generate AI Program, Update nutrition plan); **Workout Review** (day → exercise → charts, log, **Progression** box); **Program Roadmap** card (header + progress bar, phase cards, *Edit Program*, Preview, Plan history); **Performance Taper**; Program History / versions; the V12 Assessment and onboarding checklist; coach notes.
- **Goals tab:** weight goal and goal score, AI goal insight, milestones.
- **Nutrition tab:** the plan, macro calculator, adherence.
- **Program Phase tab:** program start date, top/sub phase for the AI generator, the phase note, and phase history. The current phase itself changes by activating the next phase on the roadmap; an emergency override (label only, reason required) is tucked away. The AI phase recommendation now lives in the current phase's window on the roadmap.
- **Head Coach tab:** *Review This Check-In*, then Approve / Modify / Defer / Reject, *Record outcome*, *Send to Client via Coach Messages*.
- **Client Settings** (from the page header): client type, goal, access window, sync from Notion.

### Roadmap tools (on a client's Overview)
- **Edit Program** (the one roadmap editor, 4 steps): Details (name, description, duration, and the three switches) → Phases (*Generate Roadmap*, *Generate plan details*, *+ Add Phase*, per-phase *Plan details*, reorder, remove) → Exit Criteria → Review → *Save program*.
- **Phase card:** click the name for Overview / Activities / Criteria / Notes. Buttons: *Edit criteria*, *Plan details*, *Draft workouts*.
- **Draft workouts:** *Build draft from plan* → edit → *Save draft* → *Review & activate…* → preview → (reason if criteria unfinished) → *Activate phase*. Afterwards: *Undo this transition*.

### Progression (left menu)
Tabs: **Review queue**, **Method reference**, **Metric definitions**, **AI program notes**.

### Leads / CRM
Board of leads by status. Statuses: New, Applied, Accepted, Closed Lost, Follow-up Later, Price Objection, Not Ready.

### Business + Content
Daily outreach and content numbers you type in, rolled up weekly.

### Assessments
Pre-assess a prospect before you build a program; saved by email.

### Library
Guides, recipes and resources, in folders, that clients can browse.

## CLIENT (coaching tier)

| Menu | What it is |
|------|------------|
| **Home** | Status, reminders, today's check-in, roadmap (stepper, current phase, quick stats), milestone bars, nutrition card, how you're tracking |
| **Check-In** | **Daily** (Today screen) and **Weekly** check-in |
| **Workouts** | Pick the day and exercise, log sets, warm-up tick, optional RIR/RPE, **rest timer bar**, **Coach target** |
| **Progress** | Charts: weight, strength, body, habits, notes (hidden if progress tracking is off) |
| **More** | Nutrition, Schedule, Habits & Assessment (program-only), Library, First 30 Days (Day 0 to Day 30), Program |

Program-only clients get: Home, Plan, Workouts, Progress, More (no check-ins). Starter clients get: Home, Workouts, Schedule, Library.
