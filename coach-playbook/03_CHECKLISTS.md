# Checklists (read aloud, then have the coach say each back)

## Daily (about 15 minutes)
1. Open **Overview**. Glance at the number cards.
2. Work **Alerts & At-Risk**: click each row, read the evidence, decide: message, adjust, or note it.
3. Clear **Onboarding alerts**, then **Plan Checkpoints Due** and **Phase Check-ins Due**.
4. Answer **client messages**.
5. Open **Progression → Review queue**; work the top items.
6. **Leads / CRM**: clear New, give every lead a status.
7. **Business + Content**: type in today's numbers.
8. Remember: you are reading yesterday's data.

## Weekly (about 60 minutes)
1. Read every weekly check-in note and answer every question.
2. Check **Plan vs actual** on each current phase; act on Behind, Review and Ready to advance.
3. Prepare phase moves for clients whose phase ends within two weeks (Draft workouts → review).
4. Mark finished checkpoints done.
5. Look for quiet clients (logging status poor) and message them personally.
6. Review the Progression review queue to zero.

## Monthly (about 2 hours)
1. Read and send the monthly client recaps.
2. Review goal scores and goal insights for clients off track.
3. Compare nutrition targets with body-weight trend; update plans where needed.
4. Check upgrade requests and program-only clients who might move up.
5. Look at Plan history for any roadmap you changed; make sure the current plan still matches the client.
6. Publish any new foods in Notion, then sync.

## New client (Day 0)
1. Lead is **Accepted** and the client has an account.
2. Client completes the assessment.
3. You **Review assessment & goals**.
4. **Generate AI Program** (More Actions) with the right Notion template; read and edit it.
5. Set the weight goal and milestones.
6. Build the roadmap (Edit & Generate Roadmap → Generate Roadmap → Generate plan details → Save Roadmap). Make sure every phase has exit criteria and checkpoints, including the Day 90 review.
7. Choose the three switches in Edit Program step one.
8. **Confirm roadmap & program**.
9. Send a welcome message.

## Moving a client to the next phase
1. Open the Program Roadmap card; click the finished phase and review its criteria; tick what is truly met.
2. On the next phase card click **Draft workouts**, build, edit, save.
3. **Review & activate…**; read the list of changes; add a reason if criteria are unfinished.
4. **Activate phase**. Open the client's Workout Review to confirm the new exercises.
5. Message the client about what changed and why. Undo is available if needed.

## Setting a progression rule on an exercise
1. Client → Workout Review → open exercise → Progression box.
2. Pick the method, fill in every setting, **Save settings**.
3. After the client's next session: **Calculate recommendation** (or use the Review queue).
4. Read the reasons; Approve, Edit and approve, or Reject.
5. Check that the client now sees the Coach target.

## Building a taper (at least two weeks before the event)
1. Client Overview → **Performance Taper → New taper**.
2. Enter event date, length, reduction %, volume unit, reference period, training days.
3. Add event-specific lifts, intensity to hold, and flag rules if you want them.
4. **Calculate preview**; fix anything it lists; **Create**.
5. During the taper check the review flags; override a session only with a written reason.
